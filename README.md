# 数模写作训练站

14 天备赛学习工具 · Modeling Study Hub

面向数学建模竞赛中的论文写作任务，把审题、摘要、结构、图表表达、结果解释和论文检查拆成 14 天训练路线，并记录本地学习进度。

## 可以做什么

- 沿训练路线逐日学习，从论文阅读与审题进入模拟训练。
- 查看统计、机器学习、优化与动态模型相关的写作知识。
- 检索结构化知识库中的资料片段，并查看原文件名与页码。
- 在当前浏览器保存学习进度，供后续复习。

## 运行

页面通过 `fetch` 加载知识库，建议启动本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。直接双击 `index.html` 时，浏览器的本地文件限制可能阻止知识库加载。

## 内容与代码

| 路径 | 作用 |
| --- | --- |
| `index.html`、`app.js` | 页面入口、训练路线与交互 |
| `lessons.js`、`deep-lessons.js` | 训练内容与延伸讲解 |
| `learning-db.js` | 浏览器本地学习记录 |
| `data/knowledge.json` | 结构化知识库 |
| `extract_knowledge.py`、`make_asset.py` | 资料抽取与资源生成脚本 |

学习内容参考陈建业论文写作、C 题制胜之道、统计方法、优化建模与微分方程等资料。资料片段保留来源线索，仍需对照原文核验。

## 与数模协作工作区的区别

本项目用于备赛学习和写作训练。[数模协作工作区](https://github.com/Wangxy009/math-modeling-ai-assistant) 用于按赛题保存审题、代码、实验、论文和 AI 使用记录。两个仓库分别服务训练和项目执行。

进度保存在当前浏览器，不提供账号或跨设备同步。第三方教学资料的复用应核对原始授权；项目采用 AI 辅助整理与开发。
