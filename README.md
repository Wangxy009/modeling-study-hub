# 数模学习站（建模写手训练台）

面向数学建模竞赛备赛的静态 Web 学习站：以「建模写手」能力为主线，把论文视角、审题、摘要、结构、图表、结果、统计语言、机器学习、优化、动态模型、论文体检等拆成 **14 天的训练计划**，配套知识库与交叉对照练习。

## 功能特性

- **14 天训练路线**：每天一个主题，从「拆一篇国一论文」到「90 分钟模拟赛」，逐日递进
- **课程内容**：结合陈建业论文写作、C 题制胜之道、统计方法简介、优化建模、微分方程等资料整理
- **本地学习记录**：学习进度存于浏览器本地（learning-db.js），无需账号
- **知识库**：`data/knowledge.json` 结构化知识点（约 1.4MB）
- **内容管线**：`extract_knowledge.py` 从资料抽取知识点、`make_asset.py` 生成资源

## 使用方法

纯静态应用，直接打开 `index.html` 即可：

```bash
open index.html
```

## 目录结构

```
index.html           # 主页面
app.js               # 训练计划与交互逻辑
deep-lessons.js      # 深度学习内容
lessons.js           # 课程内容
learning-db.js       # 本地学习记录
data/knowledge.json  # 结构化知识库
extract_knowledge.py # 知识抽取脚本
make_asset.py        # 资源生成脚本
```

## 项目亮点

- 把「怎么学数模」本身工程化：训练计划即数据，每天的学习目标、资料、练习全部结构化
- 从作品集角度体现「学习系统设计」：计划 → 内容 → 记录 → 复盘闭环
